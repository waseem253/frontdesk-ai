FrontDesk — Booking Sequence SEQUENCE

One inbound call, end to end · the Telegram confirmation is a real message

sequenceDiagram
  autonumber
  participant C as Caller
  participant R as AI Receptionist
  participant B as Booking core
  participant T as Telegram
  participant S as SMS (Twilio)
  C->>R: "I'd like to book"
  loop slot-fill
    R->>C: ask name / service / phone / time
    C->>R: answers
  end
  R->>C: offers concrete slots
  C->>R: picks a slot
  R->>B: create booking
  B->>T: send confirmation (real, to /start-ed chat)
  B->>S: send SMS confirmation
  B->>B: log booking
  R->>C: "Booked — confirmation sent"
  Note over B,T: no token → dry-run, booking still completes
Reliable — deterministic slot-fill always completes; optional Anthropic only smooths phrasing Real Telegram — the confirmation is an actual message to the chat that started the bot Same path for outbound — Scope 2 lead → auto-call books through this identical confirm/log flow
